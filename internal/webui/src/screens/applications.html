Advanced routing, access and request policies

Optional controls for backend pools, health checks, maintenance, forward authentication and path/body policies.

Path exposure

Leave this on profile default to keep a policy you did not edit. The ha-mcp profile then installs its preset (allowlist, Authorization on /api/mcp, a long SSE timeout). See the Home Assistant MCP guide. Restricted paths and profile block lists still apply.

Publication rules

Rules run from top to bottom. All specified conditions must match. Count records a match and continues. Block returns 403. Pass ends this list and continues with the remaining security checks.

Restricted paths

Optionally limit a URL prefix to specific IPs/CIDRs. Restricting Home Assistant /api also restricts /api/websocket and can block the web UI, Companion and external API clients. New applications have no automatic LAN restriction. One CIDR per line.

Request bodies

Leave empty to use the profile. A limit also refuses bodies of unknown length (chunked uploads), and blocking multipart breaks file uploads outside the allowed paths. This reduces exposure to request-parsing flaws; it does not replace patching.
