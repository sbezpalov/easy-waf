MCP

Give clients such as OpenClaw read-only access to Easy WAF diagnostics through the Model Context Protocol.

Configure and enable the service

Connect a client

The service listens on the appliance loopback interface. For a remote client, forward the configured MCP port over SSH from the host where the client runs.

Transport
Streamable HTTP
Example client endpoint (local port 8446)
http://127.0.0.1:8446/mcp
Authentication
Use the client bearer token from EASY_WAF_MCP_TOKEN in the client's secret configuration.
Connect OpenClaw

On the Gateway host, open the SSH tunnel and register the server under mcp.servers. Run openclaw mcp probe easy-waf from the same environment to verify the connection.
