Response headers

Real client IP behind a proxy

Only requests whose source is in Trusted proxies may replace their address with the header below; others keep their own. Without this, behind Cloudflare or a tunnel every client looks like the proxy to IP lists, GeoIP, CrowdSec and rate limits.

MQTT, RTSP, ...: one per line, name listen_port backend_host:backend_port [allow=CIDR,CIDR] [off]. Raw TCP: no HTTP rules apply; the IP blacklist does. Allow each listen port in Network → Firewall.

One per line, server_name backend_host:backend_port [allow=CIDR,CIDR] [proxy] [off]. Connections for that name (or *.domain) go to the backend still encrypted, with its own certificate; no HTTP rules apply. proxy sends PROXY protocol v2 (the backend must expect it). The name must not be an application's public host.
