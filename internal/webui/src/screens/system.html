Backup and restore

          
Backup and restore are not available in the web panel. Run the packaged commands from the appliance console or an SSH session with sudo.

          
sudo easy-waf-backup --dir /var/backups/easy-waf --keep 7

          
sudo easy-waf-restore /path/to/easy-waf-backup-YYYYMMDD-HHMMSS.tar.gz

          
Restore replaces the database and appliance state. Use a protected, same-version archive and follow docs/BACKUP_RESTORE.md. The daily easy-waf-backup.timer keeps seven archives by default.
