Monitoring

          
When enabled, Prometheus can scrape GET /metrics on this management service. Access is restricted by management_allowed_cidrs only (no JWT). See docs/MONITORING.md.

          
          
A Zabbix agent may already be installed on this appliance or host. Easy Home WAF does not install or manage the agent; this toggle only opens TCP 10050 in the managed nftables ruleset from RFC1918 and loopback so the server can poll it. Do not expose 10050 to the WAN.

Notifications

          
Sent to a webhook (JSON), a Telegram chat, or both: a failed HAProxy apply, a backend server going down or coming back, a spike of blocked requests, and once a day certificates that failed to issue or renew or have fewer than 21 days left. Leave both empty to keep warnings in the journal only. The URL and token are not written to the log; redirects are not followed.
