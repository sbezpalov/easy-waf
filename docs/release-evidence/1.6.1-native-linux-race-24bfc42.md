# Native Ubuntu race run for 24bfc42

The full race suite and separate HAProxy golden gate passed on the dedicated
Ubuntu 24.04.5 VMware clone with the native Linux 6.8.0-147-generic kernel.
The source was commit `24bfc421725337c9acd95f3661dea7686c95e4c1`, tree
`2cc62b60ad8cadcf30f10d9370b2812a1018241a`. The two changes since the
previous WSL2 run were documentation files.

The run reused the exported Ubuntu CI filesystem, with Go 1.27.4, GCC 13.3.0,
HAProxy 2.8.30 and Node 18.19.1. All 866 tracked files in the offline test
archive matched the Git archive byte for byte. After module verification,
dependencies were vendored into the test archive for offline use.

The runner used a private filesystem root and separate mount, PID, IPC and
network namespaces. A temporary PostgreSQL 16.15 cluster accepted SCRAM
connections over loopback only inside the test network. The appliance database
and service sockets were outside the test namespace.

- HAProxy golden tests passed as a separate gate.
- The full Linux `go test -race -json -count=1 -p 1 -skip '^TestGoldenRender$' ./...`
  passed 858 top-level tests in 49 packages, with zero test failures, skips or
  build failures. The golden test excluded by that command ran in its own gate.
- The three tests that previously triggered reports in WSL2 all passed.
  They covered failed Apply with PostgreSQL, oversized GeoIP extraction and
  the APT log decoded-size limit. The PostgreSQL regression for unchanged
  settings also ran and passed.
- The runner exited zero and removed its temporary PostgreSQL cluster. The
  existing appliance remained on schema 028 and edge generation 7. Its strict
  baseline, active services and trusted HTTPS checks passed.

The [previous WSL2 results](1.6.1-linux-race-8c860d3.md) remain recorded as
failures of those runs. The native pass establishes independent Linux race
coverage for the same product source. It does not identify the cause of the
PBKDF2 signal or establish a clean WSL2 race run.

The private test logs remain on the VMware clone under
`acceptance-work/native-race-24bfc42/root/result`. The host-side archive
manifest and runner are in `.ai/artifacts/native-race-24bfc42/`.
