Verified on 2026-11-24 from clean commit
`11ff90f20ae55a8f936d7eebbbc0a5b879475c4e`. Changes after the packaged and
offline-tested [1dcf591 candidate](1.6.1-packages-1dcf591.md) are documentation.

## Windows developer checks

Go 1.27.4 and Node.js 26.13.1 ran natively on Windows amd64.
`go test -json -p 1 -count=1 -timeout 6m ./...` passed 801 top-level tests
in 49 packages and skipped 85 top-level tests. The environment had no
PostgreSQL fixture. A separate selection for the web UI, release checks
and HAProxy renderer also passed.

`go vet -p 1 ./...` passed with a fresh local Go cache. The initial
`go vet ./...` invocation had stopped with an EOF panic in the analyzer's
Go package importer. The retry used the same Go release and changed
the cache and parallelism.

## Ubuntu runtime checks

A disconnected Ubuntu 24.04.5 amd64 VMware guest verified the source and
tool archives before use. Go 1.27.4 ran with `CGO_ENABLED=0`. The temporary
PostgreSQL 16.15 instance used a Unix socket with TCP disabled. The test
user owned its disposable source tree and broker staging directory.
The latter was mounted in a private mount namespace so the appliance
services kept their original state directory.

`go test -json -count=1 -p 1 -timeout 9m -skip '^TestGoldenRender$' ./...`
passed 893 top-level tests in 49 packages, with 23 top-level skips.
The database migration replay test ran and passed. The first two test
runs exposed fixture permissions, first when creating temporary test
files next to the source and then in the Zabbix broker staging test.
The complete suite passed after correcting the fixture. Node was
unavailable in the Linux guest. The Windows run covered the web UI.

The golden render test passed separately. On HAProxy
`2.8.30-0ubuntu0.24.04.2`, the CI integration selection passed all five
checks and 39 subtests. This included golden configurations, live path
policies, application profiles, GeoIP and ordered publication rules.
The temporary PostgreSQL instance stopped and the guest powered off.

Race coverage remains recorded for the
[earlier candidate](1.6.1-runtime-gates-41debb4.md). Hosted CI and
verification of published signatures remain separate release gates.
