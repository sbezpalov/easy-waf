## Confirmed defect

The operator reported that sign-in did nothing and the developer console showed
errors. Microsoft Edge 157.0.4341.60 was available through native Computer Use.
The browser's console showed a CSP violation blocking the main inline script.

The actual served script had 3,872 CRLF sequences. The server allowed its raw-byte
SHA-256 source, but HTML preprocessing normalized those newlines to LF before the
browser checked CSP. A direct, certificate-verified management HTTPS probe
confirmed that the policy allowed the raw hash and rejected the browser hash.
This blocked script execution before the form could send an authentication request.

`e95ccb3` normalizes CRLF and lone CR before hashing script text and pins embedded
HTML to LF through Git attributes. The policy continues to allow only the shipped
script hash; no unsafe-inline script permission, certificate bypass or wider
script source was introduced by the fix.
