Test date: 2026-11-16, Europe/Moscow. Source commit
`6be44678a409c460e89a8713272f0293f1c32826` was tested, packaged for Linux amd64
and arm64, and installed on the dedicated Ubuntu 24.04.4 amd64 PVE dev appliance.

## User report and repair

The operator reported that the application did not show its version and also
required a CLI version query. Dashboard already had a Version card, but status
read an unset `EASY_WAF_VERSION` environment variable and returned an empty
string. A regression proved both the empty result and the ability of an
environment value to replace the reported source version.

Root `VERSION` is now embedded in Go builds, including direct `go build`.
Authenticated status and API diagnostics use that compiled value. The panel
shows it in its persistent header and Dashboard; missing or failed status is
reported as unavailable rather than a guessed version. All five Go commands
accept standalone `--version` and `-version` before service/DB setup. No runtime
environment value or file lookup is needed to obtain the version.
