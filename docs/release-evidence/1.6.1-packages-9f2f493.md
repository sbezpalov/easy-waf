confirmed the source commit and timestamp, component versions, license and
attribution. The shipped read-only smoke passed with version 1.6.1 as the
expected version. A repeat installation without the snapshot mounted
preserved CrowdSec and system APT files.

`easy-waf:easy-waf 0600`, the main env file was `root:root 0600`, and the
configuration directory was `root:easy-waf 0750`. All ten checked units were
active again and trusted HTTPS readiness returned success. The guest
powered off after acceptance.
