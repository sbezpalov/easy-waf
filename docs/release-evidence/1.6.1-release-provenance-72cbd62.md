# Easy Home WAF 1.6.1 release build provenance

against a clean clone of `72cbd625bce19a611365361e44adfcbfdb5b44a6`.
The Ubuntu 24.04 container used Go 1.27.4 and the cached nfpm development
build without network access. It checked all five executables for each

tarball entries byte for byte. Each contained the exact source revision,

settings to report provenance. A separate replay of the same build step

and About tests passed on Windows.

## Offline ISOs

Ubuntu 24.04 builders ran the ISO build on both architectures with APT
2.8.4 and xorriso 1.5.6. The arm64 builder used Docker emulation. Each
builder verified its previous ISO checksum and supplied the archived
dependencies to APT over loopback. The isolated APT solve passed for
both architectures. The package manifests and SHA-256 values of all
177 dependency DEBs per architecture matched the previous ISOs.

Both images passed `install.sh --verify-only`. The release verifier
matched the repository and payload copies of the Easy WAF DEB and the
payload checksum to the exact package above. The public CrowdSec profile
was selected and the operator snapshot was absent. All four packaged
commands reported version `1.6.1` on both architectures. Windows verified
the final ISO digests independently.
