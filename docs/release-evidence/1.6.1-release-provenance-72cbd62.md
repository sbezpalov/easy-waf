against a clean clone of `72cbd625bce19a611365361e44adfcbfdb5b44a6`.

## Offline ISOs

Ubuntu 24.04 builders ran the ISO build on both architectures with APT
2.8.4 and xorriso 1.5.6. The arm64 builder used Docker emulation. Each
builder verified its previous ISO checksum and supplied the archived
dependencies to APT over loopback. The isolated APT solve passed for
both architectures. The package manifests and SHA-256 values of all
177 dependency DEBs per architecture matched the previous ISOs.

Both images passed `install.sh --verify-only`. The release verifier
matched the repository and payload copies of the Easy WAF DEB and the
payload checksum to the exact package above. The public CrowdSec profile
was selected and the operator snapshot was absent. All four packaged
commands reported version `1.6.1` on both architectures. Windows verified
the final ISO digests independently.

## amd64 appliance installation

VMware Workstation 17.6.2 booted a fresh Ubuntu 24.04.5 guest without a
network adapter or shared folders. The installer ran from a read-only
ISO mount. A missing CrowdSec snapshot was rejected before provisioning.
Installation with the separate verified snapshot preserved system APT
sources and indexes and left the host APT test hook uncalled.

After an actual reboot, ten services and timers were active, PostgreSQL
reported schema 029, and the CrowdSec LAPI and Hub collection checks
passed. The management certificate verified HTTPS readiness. HAProxy
accepted its live configuration. All four installed files and the three
running daemon executables matched the exact DEB in the ISO.

The anonymous About endpoint returned 401. After first-operator
enrollment inside the guest, the authenticated endpoint reported the
exact source commit and timestamp, the running version and platform,
the installed component versions, Apache-2.0 text and the attribution
notice. The served panel contained the About tab.

The repeat installation ran with the snapshot unmounted, preserved
CrowdSec and system APT file checksums, and left LAPI reachable. The
fixture reported `SUCCESS` and powered off.

The [earlier offline installation and reboot results](1.6.1-current-artifacts-1faf1fe.md)
cover both `1faf1fe` images. Appliance installation of the regenerated
arm64 ISO and the GitHub Actions signing run remain open.
