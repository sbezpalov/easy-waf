## amd64 installation and reboot

The amd64 image above passed a clean installation in VMware Workstation
17.6.2 on Ubuntu 24.04.5. The guest had no network adapter and no external
IPv4 or IPv6 route. The ISO was mounted read-only at
`/mnt/Offline image #1%`. The full-profile installer rejected an absent
CrowdSec snapshot before provisioning. With a separate, checksum-verified
snapshot it completed installation and preserved the system APT sources and
indexes. The test hook in the host APT configuration did not run.

The fixture recorded a different boot ID after reboot. Ten services and
timers were active, PostgreSQL reported schema 029, and CrowdSec LAPI and
the four expected Hub collections passed. The configured management
certificate verified HTTPS readiness. HAProxy accepted the live
configuration and emitted no inherited `forwardfor` warning. All four
installed binaries and the three running daemon executables matched the DEB
in the ISO.

A repeat installation without mounting the CrowdSec snapshot preserved the
recorded CrowdSec configuration and system APT files. LAPI remained reachable.
The test reported `SUCCESS` and powered off the guest.
