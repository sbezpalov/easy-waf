CrowdSec snapshot before provisioning, completed with a verified snapshot,
and preserved the system APT sources and indexes. After reboot, ten units

executables matched the ISO package. The authenticated About endpoint

A repeat installation succeeded with the snapshot unmounted. The packaged

returned the appliance to trusted HTTPS readiness.
