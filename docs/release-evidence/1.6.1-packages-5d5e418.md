on an Ubuntu 24.04.5 VMware guest with only loopback and read-only media.
The installer rejected a missing CrowdSec snapshot before provisioning.

preserved the system APT sources and indexes.

After reboot, ten services and timers were active, PostgreSQL reported
schema 029, and the management HTTPS readiness, CrowdSec LAPI and live
HAProxy configuration checks passed. All four installed executables and
the three running daemon executables matched the ISO's DEB byte for byte.
Authenticated About reported the exact source commit, commit timestamp,
component versions and attribution. A repeat installation with the
snapshot unmounted preserved the CrowdSec and system APT files.
