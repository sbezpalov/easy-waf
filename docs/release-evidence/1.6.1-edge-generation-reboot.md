# Edge generation across reboot on schema 028

The dedicated Ubuntu 24.04.5 VMware clone recovered HTTPS and all ten checked
units automatically on the previous package, but the saved and applied edge
generation moved from 5 to 6 with identical settings and HAProxy revision.
The API syncs environment settings at startup, and the PostgreSQL settings
upsert fired the update trigger even when the stored value was unchanged.

Commit `2b025f6` skips the UPDATE when the existing and proposed values match.
The real PostgreSQL 16 regression failed on the old SQL (generation 3 instead
of 2) and passed on the fix. It also verifies that an insert and a changed value
advance the generation. Linux race tests for store, bootstrap and engine, vet
and golangci-lint passed. Both release architectures built from tree
`4e8d54e5128651fc6e35dfa9a2ea64d52af965b5` and passed package inspection.

The amd64 DEB, SHA-256
`c4544a391a205ee6bcda4d90d2b85db0cdb5a29ae75a7f647200199330903432`,
was installed through APT after a matched backup. APT exited zero. The
delivery driver's comparison failed at generation 6 versus 7. Its baseline
predated the backup, which stops and restarts the old API, so it cannot
attribute the increment to a specific phase. All other compared categories
matched. A fresh backup on the fixed package kept generation 7.

One subsequent reboot changed the boot ID from
`dbb89d3f-bba8-4b5c-8232-dc0a7b9a266c` to
`73ae0069-fab2-4531-b168-339e61b449a3`. With no manual service starts, all
ten checked units were active and enabled, with no failed units. Saved and
applied generations remained 7, the revision hash matched, and pending
remained false. Schema 028, full settings/application/certificate records,
selected private file hashes, permissions, bundle CSP, installed and running
payloads, fresh HAProxy stats and the idle broker RPC all passed the strict
probe. A separate Windows client confirmed the same trusted test certificate
and exact marker over HTTPS.

Private checkpoints and probe logs remain on the clone. Recovery uses the
retained previous DEB and matched pre-upgrade archive; no rollback was needed.
This follow-up covers the fixed package's boot recovery and focused Linux tests.
It does not rerun the full local race suite or exercise rollback to schema 027.
