## Installation on a clean VMware guest

Ubuntu 24.04.5 amd64 booted in VMware Workstation 17.6.2 on Windows with no
network adapter. The test confirmed
loopback was the only active interface and no external IPv4 or IPv6 route was
available. Easy WAF, HAProxy, PostgreSQL, CrowdSec and the SPOA bouncer were
absent.

The ISO was mounted read-only at `/mnt/Offline image #1%`. The installer refused
to provision CrowdSec until the operator snapshot was supplied. After the test
mounted the separate read-only snapshot and verified its SHA-256 manifest,
the full public profile installed successfully. The host's APT source files
and indexes matched their pre-installation checksums, and an APT hook placed
in the host configuration for the test never ran.
