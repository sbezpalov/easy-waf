## Repair and regression gates

checkout because b5fa4a4 did not package restore. Adding only the operator link
would also fail: the old script located libraries next to the link instead of
the target. Its real symlink regression failed with
`operator commands/lib/env-file.sh: No such file or directory` before the fix.

Restore now resolves its script directory through `readlink -f`, matching backup
and diagnostics. Restore behavior, database transaction handling, service control
and secret permissions are unchanged. Operator documentation describes the
packaged command and retains the source invocation for older installations.

The existing real-tar permissions fixture now exercises the source invocation
and an executable relocated symlink with spaces in its path. Only DB, service
and ownership leaves are mocked; extraction, parser and mode assertions are real,
with `/etc/easy-waf` confined to a private container tmpfs. A first archived-source
run exposed a fixture assumption: git stores the source script as 0644. The test
now uses Bash for source and 0755 for its simulated packaged copy, then tests the
operator link directly. No production mode was changed to satisfy the fixture.

Full `make verify`, backup-publication and restore-permissions regressions passed
on the exact staged tree that became 677a499. Windows Git Bash syntax and native
ShellCheck 0.11.0 passed; Linux ShellCheck 0.9.0 passed through verify. Linux tests
used the existing offline Ubuntu/Go 1.27.4 container without network access,
host PID namespaces or a Docker socket. No runtime Go code or dependencies changed;
the full Go race/vulnerability suites were not rerun for this packaging repair.
