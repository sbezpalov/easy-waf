## Repair and regression

The previous browser observation found that Escape did not dismiss application
deletion confirmation. The shared handler also focused the destructive action
immediately. A Node regression executing the actual embedded handler failed
before repair on this initial focus.

Destructive confirmations now focus Cancel; ordinary confirmations retain their
existing affirmative focus. Escape cancels, Tab/Shift+Tab wrap between the two
actions, and closing restores the invoking control if it remains connected.
The box has a dialog role, modal semantics and a plain-text accessible name.
Repeated completion is ignored. Existing button and backdrop behavior remains.

Windows Go 1.27.4 / Node 26.13.1 full webui tests, vet, scoped lint (zero issues)
and full embedded-script syntax passed. Ubuntu 24.04 / Go 1.27.4 full webui
race tests and scoped lint passed in the existing isolated container without
network or database. Scenarios cover keyboard navigation/cancellation, explicit
confirmation/cancellation, backdrop versus inside clicks, focus restoration and
a detached invoking control. The committed tree matched the Linux test archive.
