## Offline ISOs

Both images passed their internal verification and a clean APT dependency
solve. APT explicitly selected arm64 for the arm64 pass. All 177 dependency
checksums per architecture matched the [previous payloads](1.6.1-packages-7eeb6b2.md#offline-isos).
Both embedded copies of each DEB matched the standalone package. The ISO
entry point and the enclosed installer, upgrade and firewall scripts and
helpers matched the exact commit.

## amd64 appliance installation

A clean Ubuntu 24.04.5 VMware guest mounted the exact ISO read-only
and used only loopback networking. The installer rejected a missing
CrowdSec snapshot before provisioning. With the verified snapshot, it
completed even when the invoking environment supplied an external binary
directory, disabled package installation and requested local binaries only.
The installed binaries and running services matched the ISO's DEB.

After reboot, authenticated About reported the exact Git revision and
timestamp, and the shipped read-only smoke check passed. Repeat installation
with no mounted snapshot preserved CrowdSec and the system APT sources and
indexes. The shipped firewall repair switched the Zabbix rule without
restarting nftables or losing the management guard and an unrelated table.
Installed backup and restore recovered synthetic database, state and
configuration values, restored ownership and modes, and returned the
appliance to trusted HTTPS readiness.

## Direct amd64 package upgrade

A disconnected Ubuntu 24.04.5 clone ran the
[authenticated 1.6.0 DEB](1.6.1-release160-migrations.md) on a fresh trial
database. Its binaries and trusted HTTPS readiness matched the expected
baseline with schema 019. APT installed the candidate directly with an
empty sources list and `--force-confold`. The candidate reached trusted
HTTPS readiness with schema 029, preserved the synthetic database setting,
the main environment file and the management certificate, and passed
validation of the active HAProxy configuration. Its running binaries and
installed backup and restore scripts matched the DEB. All four installed
commands reported 1.6.1.

The artifacts are local and unsigned. Booting this exact arm64 ISO and
verifying the published 1.6.1 signatures remain open.
