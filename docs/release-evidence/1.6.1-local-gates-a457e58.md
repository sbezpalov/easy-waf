## GeoIP archive regression and Linux race

The full Go suite and golangci-lint 2.15.0 passed on Windows amd64 with Go
1.27.4. Focused Linux amd64 race tests passed for the archive budget,
including earlier files, tar headers and database bytes, and for the
API's HTTP 413 error mapping.

The full Linux race suite on Ubuntu 24.04.5 amd64 used Go 1.27.4, GCC 13.3
and PostgreSQL 16.15 on a Unix socket. It passed 924 top-level tests in 50
packages with four skips. The PostgreSQL version and migration checks ran,
and the separate golden render passed. The five HAProxy 2.8.30 integration
checks passed for application profiles, publication rules, GeoIP, path policy
and configuration validation. The separate root cases passed for validation
from a private HAProxy working directory and APT execution locks and shutdown.

## amd64 offline appliance and GeoIP upload

A disconnected Ubuntu 24.04.5 VMware guest installed the exact amd64 ISO
under `umask 077` with its verified CrowdSec snapshot. After reboot, ten
units were active, schema 029 was ready and management HTTPS used the trusted
certificate. Installed and live executables matched the DEB. Authenticated
About matched the source commit and timestamp.

The confirmed operator uploaded a small synthetic Country MMDB in a `.tar.gz`
with a notice file before the database. The installed API returned HTTP 200,
reported the expected database type and country and wrote the exact database
bytes. The archive-budget boundary and the HTTP 413 mapping were covered by
the regression tests above.

Rollback status under contention, firewall confirmation and timed rollback,
time zone, both Zabbix variants, repeat installation without the snapshot and
installed backup and restore passed. The guest powered off after reporting
success.

## arm64 offline appliance and GeoIP upload

A fresh Ubuntu 24.04.5 arm64 guest under QEMU 8.2.2 used the offline ISO
whose SHA-256 matched the table above. The guest had only loopback and
read-only installation media, and its clock predated the verified APT
metadata. The installer rejected a missing CrowdSec snapshot before
provisioning, then installed the full profile with the verified snapshot
and preserved system APT sources and indexes.

After reboot, ten units were active, schema 029 was ready, management HTTPS
used the trusted certificate, CrowdSec LAPI answered and live HAProxy
configuration validated. The installed binaries and running daemon executables
matched the DEB, and authenticated About matched the source revision and date.

The installed API returned HTTP 200 for the same synthetic `.tar.gz` with a
notice before the Country MMDB, reported `GeoLite2-Country` and the expected
country `US`, and persisted the exact database bytes. Checks also passed for
time zone and journal formatting, rollback status under contention, firewall
confirmation and timed rollback, both optional Zabbix services and their
inventory, and repeat installation without the snapshot. The guest reported
success and powered off. The guest check and outer runner both exited zero.
