## Installed upgrade

1. The test took a matched private backup and temporarily renamed the clone's
   original database. The trial used an empty database at the configured name.
2. The first attempt reached the 1.6.0 installation and migration 019, then
   stopped at the API version assertion. The old API reads its version from
   `EASY_WAF_VERSION`. The retry supplied the historical installer value
   `1.6.0` and started with a fresh trial database.
3. The retry verified 1.6.0 through dpkg and the authenticated API, exact
   installed and running binaries, and 19 migration records ending at 019.
   It created a fixture publication and certificate through the management API.
   An HTTPS client that trusted the fixture CA verified the leaf and the marker
   response before upgrading.
4. APT installed the amd64 1.6.1 DEB directly over 1.6.0 with `--force-confold`.
   The resulting ledger contained 28 records ending at 028. Installed and
   running binaries matched the candidate payload. The original publication
   and certificate IDs, checked row fields, certificate and environment file
   hashes, served TLS leaf and HTTPS response were preserved. Authenticated
   HAProxy statistics showed the backend UP. Saved and applied generations
   matched, with no pending change or manual HAProxy restart.

## Return and scope

The test returned the original database and the pre-test `2bdeca3` package,
then used packaged restore on the matched archive. Strict state and payload
checks passed, ten services were healthy, and an independent Windows client
verified the original trusted HTTPS marker. The backup timer was active, no
systemd units were failed, and both owned scratch databases were removed. The
retry unit ended with `Result=success` and `ExecMainStatus=0`. The private
archives stayed on the clone.

This run covers the direct APT transition on amd64. The clean OS installer,
`scripts/upgrade.sh`, manual browser Apply, arm64 runtime, and signed-release
acceptance of this candidate remain separate checks. The PVE appliance was
outside the test scope.
