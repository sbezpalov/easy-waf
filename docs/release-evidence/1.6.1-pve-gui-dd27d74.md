# Current GUI and appliance package on PVE

On 2026-11-18, the dedicated PVE dev appliance moved from the
`9cfc841` package to the amd64 DEB built from
`dd27d747859cf784b15bf1c961f9f3a0b9973381`. Before APT, the PVE served the
GUI from before `9628bae`. The new DEB includes the subsequent GUI/UX
commits, the OpenClaw profile, the Edge changes workflow, and schema 028.
Its packaged inputs matched the checked-out `main` at the time of delivery.
The package was the locally verified DEB used in the
[offline ISO build](1.6.1-offline-iso-3ef58b7.md), SHA-256
`56e7085972678e0cf2b467c72a319f09d75e2755c62014375f9147560a5c98ff`.

Before reinstalling, the driver matched the retained `9cfc841` package
against all four installed Easy WAF executables. It retained that package
and a root-private matched backup on the VM. The backup's custom-format
PostgreSQL dump identified the database selected by the running API.
APT used the local DEB with existing conffiles and a dry run limited to
reinstalling Easy WAF.

The installed four executables and the three running daemons matched the
new DEB. All ten checked services and timers were active. The active API
database was on migration 028, Edge changes reported a known applied state,
the broker reported APT idle, and HAProxy reported the HTTPS frontend open
and a backend up. Full application, certificate, and settings inventories,
the environment file, management certificate, and the trusted HTTPS check
matched the pre-installation baseline. A separate Windows HTTPS request
directed to the VM returned HTTP 200 with normal TLS validation and the
expected fixture response.

The management HTML matched the embedded artifact in both the appliance
probe and a separate Windows download, SHA-256
`c628c95b5b79a17d4a5dede58283be98200d377429be2dd7bd02bcf919c134a0`.
The appliance probe also checked the inline JavaScript hash against CSP.
The initial post-install probe queried the default database, which was
still on migration 027. A corrected probe queried the database selected by
the running API and passed without a second package installation.

The matched DEB and backup are the rollback pair. Restore the matched
schema 027 checkpoint before resuming the older control plane. That
downgrade remains untested, as recorded in the
[VMware upgrade evidence](1.6.1-vmware-schema-028.md). The PVE run verifies
deployment and read-only UI/API checks. Native browser Apply remains covered
by the [separate VMware run](1.6.1-browser-apply-79d7f16.md).
