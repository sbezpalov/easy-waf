### Package lifecycle, nftables and PostgreSQL archive follow-up

These checks ran on commit `0688256fd4d2ceef3c6c933f0c1b91e2068c1f8b`,
tree `c4442a3ca5e73296afca0517e05745e5ae5c79b1`. Its diff from
`39742bd` contains only documentation.

- The normal package-restart launcher passed all seven systemd/APT cases in
  17.72 seconds. They covered the synchronous restart negative control,
  package lock waiting, worker identity, broker restart, worker refresh,
  stopped services and worker removal. The network-disabled container had a
  private cgroup namespace. The cached image's boot script matched the source,
  and the launcher removed its container after completion.
- The nftables rollback test ran on Ubuntu 24.04.5 amd64 in an empty, private
  network namespace on VMware, with real nftables 1.0.9 and Linux
  6.8.0-147-generic. The test replaced and removed managed tables, preserved a
  foreign table, rejected a damaged backup atomically and recovered after
  repair. The appliance's stateless ruleset matched before and after, and an
  independent Windows HTTP request returned the expected fixture response.
  The guest verified the test binary SHA-256
  `fb5e1c7c8defbdc50b639207b348eed2cd79f213c840d39743b79e00fbc724fe`.
- The PostgreSQL archive fixture ran as an unprivileged user on the same guest,
  using its own PostgreSQL 16.15 cluster and Python 3.12.3. Real SCRAM
  authentication, dump and restore passed. It checked URI and service-file
  precedence, password handling outside command arguments, exact trailing
  whitespace and sanitized errors for malformed connection settings.

The VMware guest was powered off after the checks.

amd64 container with [Cosign 3.1.4](https://github.com/sigstore/cosign/releases/tag/v3.1.4),
the version pinned by the Release workflow. The Cosign executable matched
the immutable release asset SHA-256
`424e2c97d0b45fd7a6b608a87f090f35633f4c23ece5f092d48bba11aaf4bbfa`.

- The genuine manifests for [v1.6.0](https://github.com/sbezpalov/easy-waf/releases/tag/v1.6.0)
  and [v1.7.0-rc.1](https://github.com/sbezpalov/easy-waf/releases/tag/v1.7.0-rc.1)
  each verified against the GitHub Actions issuer and exact tagged workflow.
- The release verifier authenticated the published v1.6.0 amd64 DEB. The
  normal downloader authenticated and unpacked the v1.6.0 amd64 tarball.
  The DEB metadata reported version 1.6.0 and architecture amd64.
- Cosign rejected the stable bundle when asked to verify the prerelease
  identity and when a byte was appended to the signed manifest. The
  artifact verifier rejected an altered DEB against the still-valid manifest.

This establishes compatibility with the published predecessor signatures.
Verification of signed v1.6.1 assets still requires a v1.6.1 publication.
