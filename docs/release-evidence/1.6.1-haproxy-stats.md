dedicated Ubuntu 24.04.4 amd64 PVE dev appliance used in the

not approval of every release gate or a new pristine installation.

## Confirmed cause and repair

HAProxy 2.8.30-0ubuntu0.24.04.2 was running, but the configured runtime stats
socket pathname was absent. Dashboard statistics reported the resulting Unix
socket connection error. A successful HTTP response from `/api/v1/stats/haproxy`
alone did not establish that collection worked: its JSON contained an error.

An isolated HAProxy master/worker fixture established that config validation
preserved the socket and a normal reload preserved it. Unlinking the pathname
before reload reproduced its disappearance: HAProxy reused its inherited
listener, leaving it unreachable by pathname. The appliance drop-in contained
exactly that pre-reload unlink command.

The fix removes the unlink from `ExecReload` in both the generated and packaged
drop-ins, retaining cold-start cleanup in `ExecStartPre`. Smoke now checks
authenticated runtime stats after Apply and rejects a collector error even
when HTTP status is 200. No privilege or network-policy relaxation was needed.
