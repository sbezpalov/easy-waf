# Easy WAF 1.6.1 release acceptance

On 2026-11-24, the [release workflow](https://github.com/sbezpalov/easy-waf/actions/runs/45479811355)
published [v1.6.1](https://github.com/sbezpalov/easy-waf/releases/tag/v1.6.1)
from `b6b672140675f91c35334325cea57a7319247543`. The SHA-256 digests of all 12
downloaded assets matched GitHub's release metadata. Cosign verified the
GitHub Actions signing identity for `v1.6.1` on `SHA256SUMS` and both offline
ISOs. The two DEBs, two tarballs and two ISOs also matched their release
checksums.

## Mobile acceptance after upgrade

The appliance was upgraded through APT with the published amd64 DEB. The
pre-upgrade backup and rollback package were retained and passed checksum
verification. After installation, the running executables matched the
published package and the management readiness endpoint returned HTTPS 200.

- The operator opened Home Assistant on a phone using mobile data and saw no
  certificate warning. HAProxy recorded HTTP 200 for external `GET /`.
- The operator then opened Companion, waited for the dashboard to load and
  closed the app. HAProxy recorded two external HTTP 101 upgrades on
  `/api/websocket` from the same client. The connections lasted approximately
  7 and 62 seconds.
- HAProxy recorded zero HTTP 429 responses for that client during the Companion
  check. A separate preceding browser check recorded one HTTP 429.
